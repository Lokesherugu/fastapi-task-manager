# Personalized Task Management System

A full-stack task management application built using FastAPI and MySQL.

## Features

- Add tasks
- View tasks
- Edit tasks
- Delete tasks

## Tech Stack

- Python
- FastAPI
- MySQL
- SQLAlchemy
- HTML
- CSS
- Jinja2 Templates

## Run the Project

```bash
pip install -r requirements.txt
uvicorn main:app --reload
